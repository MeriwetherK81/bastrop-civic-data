# Bastrop County Checkbook public data

Public, sanitized data layer for Smithville Texas News. `checkbook/index.json` lists available fiscal years. Each year gets its own folder using the same normalized public schema.

This package contains **no private canonical source data** and no suppressed individual detail. Aggregate-only privacy categories remain represented only as public aggregate records so totals reconcile.

Scope: Bastrop County accounts-payable check-register activity, not the county general ledger or all county spending.
